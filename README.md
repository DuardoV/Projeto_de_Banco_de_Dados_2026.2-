# Projeto de Banco de Dados-2026.2 - Sistema de Gerenciamento de Estúdio de Gravação Musical

Projeto desenvolvido para a disciplina de **Banco de Dados**, da Universidade de Brasília (UnB).

## Sobre o projeto

O projeto consiste no desenvolvimento de um sistema de gerenciamento de um estúdio de gravação musical, com o objetivo de centralizar e organizar as informações relacionadas às atividades do estúdio, focando no Banco de Dados.

O sistema busca facilitar o gerenciamento de artistas, funcionários, estúdios, salas, equipamentos, agendamentos, sessões de gravação, pagamentos e faixas gravadas.

## Objetivos

Desenvolver uma solução que permita organizar as informações do estúdio por meio de um banco de dados relacional, proporcionando maior controle sobre os recursos disponíveis e as atividades realizadas.

## Funcionalidades previstas

- Cadastro e gerenciamento de artistas e funcionários.
- Gerenciamento de estúdios, salas e equipamentos.
- Controle de horários e agendamentos.
- Registro e acompanhamento de sessões de gravação.
- Gerenciamento de faixas gravadas.
- Controle de pagamentos.
- Operações de cadastro, consulta, atualização e exclusão (CRUD).
